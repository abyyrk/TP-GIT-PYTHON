#TP_GIT_PYTHON
##Dans ce tp j'ai créé un petit programme en Python appelé "Mon assistant de révision" son objectif est d'aider l'utilisateur à organiser une séance de révision
##Le fichier main.py contient le code du programme  il affiche un message de bienvenue et demande à l'utilisateur son prénom la matière qu'il souhaite réviser et la durée prévue en minutes
#Versions V1 à V4:
##v1:
###J'ai commencé par créer le fichier main.py sur mon ordinateur Cette première version affichait simplement un message de bienvenue
##v2:
###J'ai modifié le programme pour qu'il demande le prénom de l'utilisateur et j'ai envoyé mon travail sur GitHub avec git push pour la première fois
##v3:
###J'ai ajouté sur GitHub une question pour demander quelle matière l'utilisateur souhaite réviser et ensuite récupéré cette modification sur mon ordinateur en utulisant git pull.
##v4:
###J'ai ajouté sur mon ordinateur une question pour connaître la durée de révision en minutes et j'ai envoyé cette nouvelle version sur GitHub avec git push
##comment exécuter le programme:
###Ouvrir Visual Studio Code
###Cliquer sur File > Open Folder et sélectionner le dossier TP_Git_Python
###Ouvrir le fichier main.py
###Cliquer sur ▶ Run Python File en haut à droite de l'éditeur
###Dans le terminal intégrésaisir son prénom puis appuyer sur Entrée
###Saisir la matière à réviser et appuyer sur Entrée
###Indiquer la durée de révision en minutes et appuyer sur Entrée
##Commandes Git utilisées:
###git init : initialise un dépôt Git dans le dossier du projet pour commencer à suivre les modifications
###git add : prépare les fichiers modifiés pour le prochain enregistrement
###git commit : enregistre une version du travail dans l'historique Git
###git push : envoie les modifications de mon ordinateur vers GitHub
###git pull : récupère sur mon ordinateur les modifications présentes sur GitHub
